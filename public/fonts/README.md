# Thư mục Font hệ thống LMS THPT Nguyễn Quang Diêu

Thư mục này dùng để lưu trữ các tệp phông chữ (Fonts) tùy chỉnh của hệ thống.

## Hướng dẫn sử dụng:
1. Bạn có thể sao chép hoặc tải các tệp font (`.woff2`, `.woff`, `.ttf`, `.otf`) vào thư mục `/public/fonts/`.
2. Đặt tên tệp theo các quy ước sau để hệ thống tự động nhận diện và áp dụng toàn hệ thống:
   - **Chữ thường (Regular):** `custom-font.woff2`, `custom-font.ttf`, `font.ttf`, hoặc `regular.ttf`
   - **Chữ đậm (Bold):** `custom-font-bold.woff2`, `custom-font-bold.ttf`, `font-bold.ttf`, hoặc `bold.ttf`
   - **Chữ vừa (Medium):** `custom-font-medium.woff2`, `custom-font-medium.ttf`, hoặc `medium.ttf`
3. Bạn cũng có thể mở tệp `fonts.css` để thêm bất kỳ quy tắc `@font-face` tùy chỉnh nào nếu cần.
